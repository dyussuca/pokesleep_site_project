開発日誌 #005 改善・修正

サイトをまるっと改善しました！表示速度アップ・スマホ最適化・不具合修正まとめ

📅 2026年10月15日 ✍️ dyussuca

今回は新機能ではなく、サイト全体の「見えにくいところ」をまとめて手入れしました。
使い方は何も変わっていないので、いつも通り使ってもらえればOKです。やったことをざっくり並べておきます。

⚡ 表示が速くなりました

  • 料理計算機のトップを開いたとき、最初に表示されるまでの時間を大幅に短縮（スマホ回線想定のテストで約13秒 → 約3秒）
  • 料理画像をすべて軽い形式（WebP）に変換。グラフ用の部品やリザルト画像用のデータは、使うときだけ読み込むように変更
  • ブログのサムネイルやアイコン画像も軽量化

📱 スマホで使いやすくしました

  • トップのタブを2列に並べて、開いてすぐ本題が見えるように
  • 料理記録は1食を1行にまとめて、21食分の入力がスクロール少なめに
  • iPhoneで入力欄をタップしたときに、画面が勝手にズームしないよう調整
  • ボタン類を指で押しやすい大きさに。小さい画面のスマホで横にはみ出していた部分も修正
  • レシピレベルの調理回数バーを1週間分（平日0〜18回 / 日曜0〜3回）に縮めて、狙った回数に合わせやすく（数値入力なら従来通り最大100回 / 50回）

🛠️ 不具合を直しました

  • EXP計算機を開いた直後、結果が「0日」のままになっていた問題を修正（何か入力すれば計算されていました）
  • 画面幅によって、上部の「ブログ / EXP計算機 / お問合せ」ボタンがタイトルに重なっていた問題を修正
  • 料理記録タブの初期表示で、存在しない料理の画像を読みに行っていた問題を修正

🎨 見た目まわり

  • ダークモードを全ページで統一。スマホ/PCのダーク設定に自動で合わせます（Ctrl + Shift + L で手動切り替えも可能）
  • トップのヘッダー背景画像を外して、シンプルなグラデーションに
  • 存在しないページを開いたときに、専用の「ページが見つかりません」画面を出すように

地味な更新ですが、特にスマホで外出先から開いたときの体感はかなり変わったと思います。

「ここが使いにくい」「表示が崩れてる」などあれば、お問い合わせフォームから気軽に教えてください！
